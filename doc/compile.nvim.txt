*compile.nvim.txt*   Plugin for compiling arbitrary commands with :make

Allows to populate the |Quickfix| list with arbitrary commands. This is done by
temporarily changing the "makeprg" variable and then calling `:make`. Provides
two commands : `:Compile` and `:Recompile` that respectively compile an
arbitrary command, and compile the last command.

COMMANDS

:Compile {cmd} [arguments]                                     *:Compile*
          Executes the {cmd} with [arguments] and puts the result in the
          |Quickfix|. This is done by temporarily changing the "makeprg"
          with the given command, and calling `:make`.

:Recompile                                                     *:Recompile*
          Executes the last command given to `:Compile`.
